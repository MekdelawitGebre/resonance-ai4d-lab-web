# Resonance AI4D Lab Web

**[Visit the Live Site](https://resonance-ai4d-lab-web.vercel.app/)** | **[GitHub Repository](https://github.com/MekdelawitGebre/resonance-ai4d-lab-web)**

This is the official website for the Resonance AI4D Lab, built with [Next.js](https://nextjs.org/), [Tailwind CSS](https://tailwindcss.com/), and [TypeScript](https://www.typescriptlang.org/).

## Prerequisites

Before you begin, ensure you have the following installed on your local machine:
- Node.js (v18.x or later recommended)
- npm, yarn, pnpm, or bun

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/MekdelawitGebre/resonance-ai4d-lab-web.git
cd resonance-ai4d-lab-web
```

### 2. Installation

Install the project dependencies using your preferred package manager:

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

### 3. Development Server

Run the development server locally:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the pages by modifying `app/page.tsx` or other pages in the `app/` directory. The browser auto-updates as you save the files.

## Available Scripts

- `npm run dev`: Starts the development server.
- `npm run build`: Builds the application for production.
- `npm run start`: Starts the production server.
- `npm run lint`: Runs ESLint to catch formatting and code quality issues.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **UI Components:** Radix UI Primitives
- **Icons:** Lucide React
- **3D Graphics:** React Three Fiber & Three.js
- **Language:** TypeScript
